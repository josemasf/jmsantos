# Preparar difusión social

Leer el artículo completo, su issue y `docs/editorial-workflow.md`.

1. Extraer problema, tesis, ejemplo y una consecuencia útil para el lector.
2. Resolver URL desde el nombre de archivo y comprobar que esté publicada si
   se necesita una llamada a leerla. Para drafts, marcar la URL y los textos como
   pendientes de publicación; no simular disponibilidad.
3. Crear un texto para LinkedIn y un texto breve o hilo para X según el encargo.
   Conservar el matiz técnico, atribuciones y límites del artículo. Comprobar la
   longitud contra las restricciones actuales del canal cuando proceda.
4. Adaptar apertura y estructura a cada canal, sin titulares engañosos, estadísticas
   nuevas ni resultados inventados. Evitar copiar todo el artículo.
5. Reutilizar la portada o solicitar adaptaciones al agente visual; comprobar
   recorte y alt antes de dar una imagen por lista.

Entregar textos por canal, URL, asset/alt y estado: preparado o pendiente de publicar.
Preparar textos no autoriza enviarlos a cuentas del autor. Enviar solo cuando lo
solicite explícitamente y haya una herramienta disponible para el canal.
